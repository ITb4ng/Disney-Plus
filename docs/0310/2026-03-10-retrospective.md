# 2026-03-10 회고 (최신화)

## 1) 오늘 해결한 핵심 문제
- 상태 UI가 컴포넌트별로 제각각이라 테스트와 유지보수가 어려웠던 문제
- 스크롤 복원 정책이 라우트/액션별로 흔들리던 문제
- CDN/이미지 실패 시 화면 품질 저하(깨진 텍스트, 깜빡임) 문제

## 2) 잘된 점
- 상태 판단(상위)과 렌더(View) 분리 방향을 명확히 잡음
- 디버그 파라미터/매트릭스로 수동 테스트 반복성이 좋아짐
- 모바일 우선 반응형 보강으로 실제 사용 환경 체감 품질 개선

## 3) 부족했던 점
- 스와이프 복원은 초기 설계가 `activeIndex` 중심이라 딥 페이지에서 불안정
- 일부 로직은 테스트 먼저 고정하지 않고 코드 수정이 앞선 구간이 있었음

## 4) 배운 점
- Detail처럼 상태 축이 두 개인 화면은 분리 설계가 필요
- UI 실패 케이스는 데이터 실패와 자원 실패를 분리해야 원인 추적이 쉬움
- “한 번 성공한 동작”보다 “반복 재현 가능한 테스트 경로”가 더 중요
