- `main -> modal -> detail` 이동 시 `location.state` 기반 debug 상태 전달이 이어지도록 반영했다.
- Landing `HeroSection`, `Top10Section`, `Main Banner`, `SearchPage`도 같은 기준으로 image fallback 디버그 상태를 맞췄다.
- 상태 UI / fallback 확인용 URL 파라미터 문서를 최신화했다.
