# 2026-03-17 작업 기록

업데이트 기준: `2026-03-17`

## 1) 작업 목표
- `v0.3.0` 범위 안에서 구조 정리와 UX 안정화
- 공용 컴포넌트와 페이지 전용 컴포넌트 경계 정리
- 모바일 인터랙션과 스크롤 흐름 보정
- 문서와 문자열 정리

## 2) 오늘 작업
- `DemoPage` -> `FeedbackPage`
- `LoginPage` -> `LandingPage`
- `NotFoundPage` -> `pages/NotFound`
- `MainPage` 전용 UI를 `src/pages/MainPage/components`로 이동
- `DetailPage` 전용 뷰와 훅을 페이지 하위 구조로 분리
- `Row`, `Category`, `DemoAction`, `Banner`의 모바일 인터랙션 기준 정리
- `MovieModal` portal, z-index, fixed, scroll lock 정리
- `Top10`, `Pricing`, `FAQ`, `Footer` 타이포와 spacing 정리
- 깨진 한글 문자열, 주석, 문서 문구 복구

## 3) 검증
- `npm run build` 통과
- 랜딩 `/` 주요 섹션 렌더 확인
- 메인 `/main` 모바일 인터랙션 수동 확인
- `Row` 관련 테스트 확인

## 4) 작업 메모
- 모바일은 hover보다 click, active, focus 기준이 더 안정적이었다.
- 구조를 먼저 정리하니 이후 수정 포인트가 명확해졌다.
- 오타 브랜치 `relaease/0.3.0`에서 작업한 내용은 `release/0.3.0`으로 `cherry-pick` 후 정리했다.
