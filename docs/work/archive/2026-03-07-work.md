## Search 진입 전환 상태 관리 및 Nav 애니메이션 연동

### 1. 검색 진입 전역 상태 컨텍스트 추가

- `SearchTransitionContext` 신규 추가
- 검색 진입 트리거(`transitionToken`, `transitionSource`)를 전역에서 공유하도록 구성
- `triggerSearchTransition(source)`로 진입 출처를 명시해 이벤트 발생 가능하게 정리

**결과**

- 검색 페이지 진입 애니메이션 트리거를 컴포넌트 간 props 전달 없이 관리 가능
- `Nav`, `DemoAction`, `SearchPage`가 동일한 전환 상태를 일관되게 참조

---

### 2. 앱 루트 Provider 구성 정리

- `index.jsx`에 `SearchTransitionProvider` 적용
- 기존 `AuthProvider`, `BrowserRouter` 구조와 충돌 없이 래핑

**결과**

- 전체 라우팅 범위에서 검색 진입 전환 상태 접근 가능
- 라우트 전환 시 애니메이션 제어 로직 확장성 확보

### 3. DemoAction → Search 진입 시 전환 트리거 연결

- `DemoAction.jsx`에서 검색 이동 직전에 `triggerSearchTransition("demo-action")` 호출
- 검색 이동 시 `from` 경로 상태를 함께 전달하도록 정리

**결과**

- 데모 액션 카드에서 검색 페이지 진입 시에도 동일한 전환 UX 보장
- 닫기/뒤로 이동 시 원래 경로 복귀 흐름 유지

### 4. Nav 애니메이션 전환 로직 개선
