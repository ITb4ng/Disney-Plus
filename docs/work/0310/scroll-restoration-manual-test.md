# 스크롤 복원 수동 테스트 문서

업데이트 기준일: 2026-03-11  
대상 프로젝트: `disney-plus-app`

## 1) 테스트 대상 라우트
- `/`
- `/login`
- `/main`
- `/detail/:type/:movieId`
- `/search`
- `/feedback`

## 2) 현재 스크롤 정책(의도)
- `PUSH/REPLACE` 이동: 이동한 라우트는 `0`(최상단) 시작
- `POP`(브라우저 뒤로/앞으로): 해당 라우트 저장 스크롤 복원
- `reload(F5/Ctrl+R)`: 같은 라우트에서 저장 스크롤 1회 복원
- 복원 직후 스크롤 변경이 없으면 다음 새로고침은 `0` 시작
- 복원 후 스크롤이 발생하면 새로고침 시 최신 스크롤로 복원

## 3) 사전 준비
1. 브라우저 탭 1개만 사용
2. 콘솔에 아래 프로브를 붙여 스크롤 로그 확인

```js
window.__scrollProbe = setInterval(() => {
  console.log("[probe]", location.pathname + location.search, Math.round(window.scrollY || 0));
}, 1000);
```

3. 종료 시

```js
clearInterval(window.__scrollProbe);
```

## 4) 핵심 시나리오와 진행 상태

### TC-01: `/main -> detail` 최초 진입은 상단
1. `/main` 진입
2. 스크롤 `200`
3. 카드 클릭으로 `/detail/...` 이동
4. 기대: `detail`은 `0` 시작

상태: `완료`

### TC-02: `detail -> 뒤로가기 -> /main` 복원
1. TC-01 상태에서 뒤로가기
2. 기대: `/main` 스크롤 `200` 복원

상태: `완료`

### TC-03: 복원 후 `/main`에서 다시 `detail` 진입
1. TC-02 직후 다시 카드 클릭
2. 기대: `/detail/...`는 다시 `0` 시작

상태: `완료`

### TC-04: `/detail`에서 새로고침 복원
1. `/detail/...` 스크롤 `220`
2. 새로고침
3. 기대: `220` 근처 복원

상태: `완료`

### TC-05: 복원 직후 무스크롤 재새로고침
1. TC-04 복원 직후 스크롤 조작 없음
2. 다시 새로고침
3. 기대: `0` 시작

상태: `완료`

### TC-06: 복원 후 다시 스크롤 -> 새로고침
1. TC-05 이후 스크롤 `180`
2. 새로고침
3. 기대: `180` 근처 복원

상태: `완료`

### TC-07: `/main` 검색/피드백 라우트 왕복 복원
1. `/main`에서 스크롤 위치 생성
2. `검색 체험하기` -> `/search` -> 닫기
3. `피드백 남기기` -> `/feedback` -> 뒤로가기
4. 기대: `/main` 기존 스크롤 복원

상태: `완료`

### TC-08: `/` 랜딩 새로고침 복원
1. `/`에서 스크롤 후 새로고침
2. 다시 스크롤 후 재새로고침
3. 기대: 현재 스크롤 유지(정책 범위 내)

상태: `완료(간헐 이슈 모니터링 필요)`

### TC-09: `/main` Row 스와이프 복원(딥 페이지)
1. Row 우측 네비 4회 이상
2. `detail` 왕복 또는 새로고침
3. 기대: 스와이프 페이지(인덱스/위치) 동일 복원

상태: `진행중(실패 재현됨)`
- 현재 관측: 기대 인덱스 `13` 대비 복원 인덱스 `6`
- 비고: `activeIndex` 기준 대신 `translate/progress` 기준 검증/복원 정합화 필요

## 5) 테스트 결과 요약(현재)
- 스크롤 복원 로직(뒤로가기/새로고침/라우트 왕복): 대부분 안정화 완료
- `/main` 검색/피드백 액션 복원: 반영 완료
- Row 깊은 스와이프 복원: 후속 보강 필요

## 6) 실패 판정 기준
- `PUSH` 이동인데 이전 라우트 스크롤이 그대로 적용됨
- `detail` 재진입 시 이전 `detail` 스크롤이 남음
- 복원 직후 무스크롤 재새로고침인데 또 복원됨
- `POP` 이동인데 저장 스크롤 복원이 안 됨
- 딥 스와이프 후 재진입/새로고침에서 스와이프 위치가 앞 페이지로 되돌아감
