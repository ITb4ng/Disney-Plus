# v0.3.0 Release Notes

날짜: `2026-03-17`

## 요약
- `v0.3.0` 범위 안에서 페이지 구조를 다시 정리하고, 랜딩(`/`)과 메인(`/main`)의 모바일 UX를 안정화했습니다.
- `DemoPage`, `LoginPage`, `NotFoundPage` 등 페이지 구조를 역할 기준으로 재배치했습니다.
- `MovieModal`, `Row`, `Category`, `Banner`, `DemoAction`, `Feedback` 흐름을 중심으로 인터랙션과 스크롤 동작을 보정했습니다.
- 랜딩 페이지의 `Top10`, `Pricing`, `FAQ`, `Footer` 스타일을 반응형 기준으로 다시 정리했습니다.

## 변경 사항

### 1. 페이지 구조 리팩토링
- `DemoPage`를 `FeedbackPage`로 정리했습니다.
- `LoginPage`를 `LandingPage`로 정리했습니다.
- `NotFoundPage`를 `pages/NotFound` 구조로 이동했습니다.
- `MainPage` 전용 UI를 공용 `src/components`에서 `src/pages/MainPage/components`로 분리했습니다.
- `DetailPage` 전용 뷰와 훅도 페이지 하위 구조로 정리했습니다.

### 2. 메인 페이지 인터랙션 안정화
- `Banner`, `DemoAction`, `Category`, `Row`, `FeedbackTeaser`의 정렬 기준을 메인 컨텐츠 폭에 맞춰 다시 정리했습니다.
- 모바일에서는 hover 개입을 줄이고 click, active, focus 중심으로 동작하도록 조정했습니다.
- `Row`는 모바일에서 영화 정보 오버레이가 기본 노출되도록 변경했습니다.
- `Category`는 active 카드만 영상이 재생되도록 정리했습니다.

### 3. 랜딩 페이지 스타일 및 반응형 정리
- `Top10`, `Pricing`, `FAQ`, `Footer`의 타이포와 spacing을 다시 정리했습니다.
- `Pricing` 타이틀 기준의 `clamp()` 스케일을 `Top10`, `FAQ`에도 맞췄습니다.
- `FAQ`, `Pricing` CSS는 과도한 토큰 사용을 줄이고 실무형 구조로 재정리했습니다.
- `Footer` 모바일 아코디언, legal/sns 간격, 리스트 간격, 로고 선명도를 함께 조정했습니다.

### 4. 모달, 라우팅, 스크롤 흐름 보정
- `MovieModal`을 portal 기반으로 옮기고, `fixed`, `z-index`, `scroll lock` 기준을 다시 정리했습니다.
- iPhone safe area와 모바일 반응형 간격도 보정했습니다.
- 비로그인 상태에서 Top10 클릭 후 로그인 시 원래 상세 페이지로 이어지도록 수정했습니다.
- 404 진입 시 항상 최상단에서 시작하고, 뒤로가기 시 이전 스크롤이 복원되도록 수정했습니다.
- 피드백 등록 이후 목록과 뒤로가기 흐름에서도 메인 스크롤 위치가 유지되도록 보정했습니다.

### 5. 문구 및 인코딩 정리
- 사용자 노출 영역의 깨진 한글 문자열을 복구했습니다.
- 깨진 주석과 인코딩 이슈를 정리해 유지보수성을 개선했습니다.
- `README`, 랜딩, 메인, 피드백 관련 문구를 전반적으로 정돈했습니다.

## 검증 결과
- `npm run build`: 성공
- 주요 랜딩 화면 및 메인 화면 수동 확인
- `Row` 관련 테스트 확인

- `1.0.0` 이전 최종 점검 성격의 리팩토링으로 관리합니다.
